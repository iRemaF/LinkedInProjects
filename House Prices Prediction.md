# House Prices Prediction

**Aljawharah S. Bin Jabr, Aljori H.Almahjoub, Arwa Alqahtani, Layan A. almugairen, May M. Alrefaie And Reema F. Almukhlifi**

This project applies **Machine Learning techniques** to predict house prices based on multiple features from a real dataset.  
It was developed as part of the **Selected Topics (Machine Learning)** course at **Princess Nourah bint Abdulrahman University, College of Computer and Information Sciences – Riyadh, Saudi Arabia.**

---

## Project Overview

The project focuses on predicting house prices by analyzing key property attributes such as:
- Lot area, living area, and total rooms  
- Year built and overall quality  
- Neighborhood and location-based variables  

Through a complete data science pipeline, we demonstrate the impact of **data cleaning, normalization, feature selection, and model optimization** on prediction accuracy.

---

## Workflow

### 1. Data Understanding  
- Loaded the dataset from Kaggle  
- Analyzed feature distributions, missing values, and correlations  
- Differentiated between **numerical** and **categorical** variables  

### 2. Data Preprocessing  
- Handled missing data (mean, median, frequent values)  
- Removed irrelevant or low-impact features  
- Encoded categorical columns  
- Normalized numerical data for better model stability  

### 3. Model Design & Implementation  
- Split data into **training** and **testing** sets  
- Applied and compared multiple regression models:  
  - Linear Regression  
  - Decision Tree Regressor  
  - Random Forest Regressor  
  - Gradient Boosting Regressor  
- Evaluated models using **R² score**, **MAE**, and **MSE**

### 4. Model Evaluation  
- Visualized model performance with scatter plots and residual errors  
- Selected the best-performing model based on **accuracy** and **generalization capability**
